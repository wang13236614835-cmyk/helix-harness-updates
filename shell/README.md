# Helix Harness 3.1.1

Helix Harness 3.1.1 完整通用版 · Windows 64位

开始使用
1. 把整个ZIP解压到一个可写文件夹，不要在压缩软件里直接运行。
2. 双击“启动Helix.bat”。自带Python和解析/科研工具，无需另装Python。
3. 首次进入“组长登录”，自行设置组长账号和密码；以后组员默认从普通登录入口进入，自行注册账号密码。
4. 点击顶部项目名→“导入项目”，选择项目ZIP，或填写本机项目资料文件夹。先核对文件清单、SHA与任务，再点“确认加入项目”。也可以“新建项目”。

完整读取
支持项目JSON、CSV/Excel任务表及PDF、Word、Excel、文本、结构文件。导入时保存原件字节与SHA，资料页可下载原件；“看原文→读取全文”读取全部文字、表格行和工作表，表格分页显示。Word全文包含正文、表格、页眉页脚及注释文本。扫描PDF没有文字层时保留原版查看，不伪造OCR内容。
文件夹建议包含 project.helix.json / project.json，或 tasks.csv / 任务表.csv / tasks.xlsx。只有资料也能导入，稍后再补任务。
当前导入容量：ZIP最大256MB，解压后最多512MB、10000文件；超过时按资料子目录分批导入。预览明确列出跳过的缓存和连接配置。

可选项目
“可选项目/通用示例.zip”：普通双人任务与资料，可用于学习操作。
“可选项目/MASH-GNN-当前项目.zip”：当前可核实的排期、来源材料、五人岗位与GNN学习卡。导入后按本机项目使用，组长固定统筹和辅助，四组员自行选岗。科研原件缺口保留在说明中，旧打卡与签署不继承。
可选项目均不自动加入空白安装。自建项目适用于其他研究或普通协作任务。

账号、同步和数据
账号、项目和账本属于当前解压目录，存于 shell/data。分发包不包含现有密码、Token、名册、私人账本或邀请码。
Notion和模型服务在界面自行连接。Notion同步任务进度，文件原件仍保存在项目中。本机程序需要这台电脑运行；云端常驻部署需另行按 cloud/README.md 配置。
需要迁移资料时：顶部项目名→“导出项目模板与资料”。它包含计划与完整原件，不迁移账号或科研签署。需要完整保留既有账号和历史时，请备份整个旧安装目录，升级只替换程序，保留 shell/data 和原配置。

便携与版本
本软件统一版本3.1.1。历史材料里出现的Workbench 2.00或旧研究版本是来源版本，不会被改造成新科研结果。
每份解压目录单独运行；18772已被其他安装占用时自动选择空闲端口，不停止其他安装。双击“停止Helix.bat”只停止当前解压目录启动的进程。
“自测Helix.bat”在临时副本执行软件测试，不改变真实项目。
“核验压缩包.bat”核对SHA256SUMS.json。运行后生成的 shell/data 与缓存不在原分发清单中。

运行环境
随包包括Windows x64 Python、PDF/Excel/Word解析库、RDKit、ToolUniverse、BioMCP和Vina，以及程序源码、通用云端部署源码。网络工具、Notion和模型调用需要网络及使用者自己的配置。
第三方许可证保留在runtime中。软件测试通过不代表科研数据、模型、疗效或候选发布已通过核验。
