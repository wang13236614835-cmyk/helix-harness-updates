# GitHub 私有更新

程序更新使用私有仓库 https://github.com/wang13236614835-cmyk/helix-harness-updates 。打卡进度继续同步到原Notion库。

首次连接：设置→程序更新→GitHub连接，使用本机已有GitHub登录，或输入有仓库权限的访问令牌。
组员需要Contents读取权限；组长发布需要Contents写入权限。令牌在Windows上由DPAPI加密，在云端由配置的加密密钥保护，加密不可用时拒绝保存。分发包和程序更新包不包含令牌。

组长发布：填写更新说明并选择“发布到GitHub Releases”。上传程序ZIP和签名清单都完成后才发布Release；中断的发布保持草稿。签名密钥只保存在组长电脑的shell/data/update-signing.json；备份时连同整个原目录保存，切勿发给组员。

组员接收：连接有读取权限的账号后，每30分钟检查；也可点“检查更新”。校验签名和SHA后，空闲90秒自动安装。新版本启动失败会回滚。原有项目、账号和Token保留。

3.1用户第一次切换：在旧版“程序更新→导入更新包”选择本次离线升级ZIP，校验通过后安装。之后连接GitHub即可。

私有仓库需向组员授予GitHub访问权限；未授权或凭据失效时会显示原因，不会把连接失败显示为已是最新版。
