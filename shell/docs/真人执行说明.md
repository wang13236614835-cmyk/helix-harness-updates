# 真人亲自执行与 AI 辅助

进入项目后，在“任务与实操”选择自己的任务，点“开始本人实操”。任务主核和交叉核都可以亲自做，使用各自登录账号，不能代填他人的操作记录。

1. 写明本次亲自做什么，选输入文件，填写工具、版本和参数。
2. 可进入“科学工具”实际调用工具，工作台会登记输入、真实输出或原始错误；也可以使用原生程序、命令行、电子表格或文献阅读工具，把日志、处理前后文件或本人摘录上传到“数据”。
3. 返回实操记录，写实际步骤、本人观察和阻塞，选择成果或日志，保存完成或受阻。不能只签字或转述 AI 结论。
4. 其他成员可查看步骤、参数、工件指纹和工具版本，在数据页核对工件。AI 草稿与真人实操分别保存；科研结果仍需要异人独立复核。

“实操记录完成”只表示操作过程有记录，不代表任务审核通过、模型合格或科研结论成立。手动上传的工件标作本人记录；工作台实际调用另记服务端观察到的工具证据。

原生个人打卡页继续保留。它们的历史、浏览器本地保存记录不会自动与 Helix 账本合并；关键实操工件需登记到当前项目。

云端只运行已安装的工具。本机随包的 Windows 科研工具不能直接当成云端已安装；云端成员可在自己电脑亲手操作，再上传工件。
