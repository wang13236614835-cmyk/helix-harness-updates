# Helix 3.1 组员注册与分发

完整本机程序使用3.0完整ZIP，解压后启动，自带Python。新安装由组长在专用入口设账号；组员用普通入口自行注册。

项目列表中启用岗位模板的项目允许本人选择空岗位并自动对应任务；其他项目由组长分配。团队默认显示匿名代号，私有登录名和密码只由本人设置。

云端团队使用组长提供的云端网址或个人加入链接。生成入口说明包可用 server/package_members.py --origin 团队网址，通用程序不预置发布者服务器。

分发不带账号、口令、Notion Token、模型Key或旧签署。自己的Notion和模型在界面连接；本机账号与云端账号分别保存。
