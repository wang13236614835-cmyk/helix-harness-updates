# Helix Harness 程序更新（私有）

这个仓库分发签名程序更新。任务打卡继续同步到Notion。

下载：Releases中的 helix-update.json 与 Helix-Update-*.zip 是自动更新使用的签名清单和程序包。

使用：组员在Helix设置里连接有仓库读取权限的GitHub账号或访问令牌；发布更新需要仓库Contents写入权限。凭据只加密存于使用者电脑。

程序包包含应用程序源码及启动文件，不包含项目资料、账本、账号密码、Notion或模型Token。完整Windows运行环境通过本机完整包提供。

3.1首次切换：使用3.1.1离线签名升级包导入安装，再连接GitHub。组长签名密钥不随包分发。
